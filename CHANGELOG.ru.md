# История изменений

## 🎉 [1.0.0] — 2026-11-07

### ✨ Добавлено

- Первый публичный релиз **Dev Tools** для VS Code 1.105+.
- Единая webview-панель с мгновенным поиском (`Ctrl+K`), навигацией по группам и 45 инструментами.
- Двуязычный интерфейс (английский / русский) с автоопределением языка VS Code и ручным переключением.
- **🔄 Конвертеры:** разбор Cron, дата и время, JSON-массив в таблицу / CSV, JSON ↔ YAML, системы счисления, JSON → код и XML → код (C#, F#, TypeScript, JavaScript, PHP; System.Text.Json или Newtonsoft.Json для JSON и `System.Xml.Serialization` для XML, плюс готовый пример десериализации для каждого языка).
- **✏️ Текст:** экранирование / снятие, сравнение списков, предпросмотр Markdown, анализ текста, сравнение текста.
- **🔐 Кодирование / Декодирование:** Base64: текст, Base64: изображение, разбор сертификата, GZIP, HTML-сущности, JWT-декодер (разбор, проверка и подпись), QR-код, URL: кодирование.
- **🧹 Форматирование:** JSON, SQL, XML. Для некорректного JSON указываются точные строка и столбец, даже если среда выполнения не сообщает позицию.
- **🎲 Генераторы:** хеш / контрольная сумма (MD5, SHA-1/2, CRC-32, HMAC), Lorem Ipsum, пароли, UUID (v4/v7/nil), ULID, пары RSA-ключей, калькулятор SemVer.
- **🎨 Графика и цвет:** инструменты цвета (конвертация, контраст WCAG, оттенки), симулятор дальтонизма, конвертер изображений.
- **🧪 Тестирование:** JSONPath, тестер регулярных выражений, проверка XML / XSD.
- **⭐ Иконки:** встроенный набор из 95 контурных иконок в стиле Tabler с поиском и копированием SVG.
- **📦 Дополнительно:** поиск дубликатов, разделение файла, генератор JSON Schema, сжатие PNG, рандомайзер, переводчик RESX, разделители текста, генератор XSD.
- **🧭 Лончер в Activity Bar**: нативное дерево из девяти групп и 45 инструментов; выбор инструмента открывает широкую панель редактора сразу на нём. Кнопка в заголовке вида открывает панель целиком.
- **📌 Кнопка в строке состояния** `$(tools) Dev Tools`, открывающая панель напрямую, без сайдбара (отключается через `devTools.showStatusBar`).
- 🗂️ Каталог инструментов генерируется из реестра (`npm run catalog`), поэтому лончер не может разойтись с реальным списком.
- ⚙️ Настройки расширения `devTools.language`, `devTools.startupTool` и `devTools.showStatusBar`.
- ⌨️ Команда **Dev Tools: Открыть Dev Tools** с сочетанием клавиш `Ctrl+Alt+D` / `Cmd+Alt+D`.
- 🌗 Оформление, учитывающее светлую, тёмную и высококонтрастную темы VS Code.
- 🔒 Полностью локальная обработка данных: без телеметрии, сетевых запросов и доступа к рабочей области, пока файл не перетащен в инструмент.
