Dev Tools собирает утилиты, к которым разработчик обращается каждый день: конвертацию JSON/YAML, тестирование регулярных выражений, разбор JWT, вычисление хешей, генерацию UUID/ULID, работу с цветом, форматирование и многое другое — в одну быструю панель внутри VS Code. Без вкладок браузера, без загрузки данных на сервер, без телеметрии.

## ✨ Возможности

- **45 инструментов** в девяти группах с мгновенным поиском (`Ctrl+K`).
- **Три точки входа:** палитра команд / горячие клавиши, лончер в Activity Bar с нативным деревом инструментов и кнопка в строке состояния, открывающая панель напрямую.
- **Два языка интерфейса** (английский / русский): выбирается автоматически по языку VS Code и переключается на лету.
- **Всё локально** — вычисления выполняются на вашей машине. В процессе расширения работают только хеширование, GZIP, генерация RSA-ключей и разбор X.509; остальное — в webview.
- **Ничего настраивать не нужно** — открыли панель и работаете.
- **Поддержка тем** VS Code: светлая, тёмная и высокая контрастность.
- **Горячие клавиши**: открытие — `Ctrl+Alt+D` (macOS: `Cmd+Alt+D`), поиск — `Ctrl+K`.

## 🚀 Начало работы

1. Установите расширение.
2. Откройте любым способом:
   - `Ctrl+Alt+D` / `Cmd+Alt+D`;
   - палитра команд → **Dev Tools: Открыть Dev Tools**;
   - иконка **Dev Tools** в Activity Bar → выберите инструмент в дереве (панель откроется сразу на нём);
   - кнопка **Dev Tools** в строке состояния.
3. Выберите инструмент в боковой панели самой панели или найдите его через `Ctrl+K`.

## 🧩 Инструменты

### 🔄 Конвертеры

| Инструмент | Что делает |
| --- | --- |
| **Разбор Cron** | Расшифровывает cron-выражение из пяти полей и показывает восемь ближайших запусков. Поддерживает `*`, `,`, `-`, `/` и макросы вида `@daily`. |
| **Дата и время** | Переводит Unix-секунды/миллисекунды/микросекунды, ISO 8601, UTC и локальное время, номера недель и относительное время. |
| **JSON-массив в таблицу / CSV** | Показывает массив объектов таблицей и экспортирует CSV с настраиваемым разделителем. |
| **JSON ↔ YAML** | Двусторонняя конвертация с проверкой ошибок и обменом сторон. |
| **Системы счисления** | Перевод целых чисел между основаниями 2, 8, 10, 16, 36 с двоичным представлением (без потери точности, BigInt). |
| **JSON → код** | Модели C#, F#, TypeScript, JavaScript или PHP из JSON; для .NET — System.Text.Json или Newtonsoft.Json. Готовый пример десериализации прилагается. |
| **XML → код** | Те же языки, но из XML-примера; для .NET используется `System.Xml.Serialization` (`XmlRoot`, `XmlAttribute`, `XmlElement`) плюс пример с `XmlSerializer`. |

## ⚙️ Настройки

| Настройка | По умолчанию | Описание |
| --- | --- | --- |
| `devTools.language` | `auto` | Язык интерфейса: `auto`, `en` или `ru`. `auto` — как в VS Code. |
| `devTools.startupTool` | пусто | Идентификатор инструмента, открываемого по умолчанию, например `converters-json-yaml`. Пусто — восстанавливать последний использованный. |
| `devTools.showStatusBar` | `true` | Показывать кнопку **Dev Tools** в строке состояния. |

## 🔒 Конфиденциальность

Dev Tools работает полностью офлайн: не собирает телеметрию, не отправляет данные и не читает файлы рабочей области, пока вы сами не перетащите файл в инструмент.

## 🛠️ Разработка

Проект полностью написан на TypeScript 7 и запускается напрямую через встроенное в Node удаление типов.

```bash
npm install
npm run compile     # сборка для разработки с source maps
npm run watch       # инкрементальная сборка
npm run catalog     # пересобрать src/catalog.ts из реестра инструментов
npm run typecheck   # tsc --noEmit
npm run package     # production-сборка + dev-tools-vscode-1.0.0.vsix (синоним: npm run vsix)
```

Нажмите <kbd>F5</kbd>, чтобы запустить Extension Development Host.

Чтобы дорабатывать интерфейс без перезапуска VS Code, поднимите статический сервер и откройте preview-страницу:

```bash
npm run preview
# http://127.0.0.1:8765/dev/preview.html
```

Preview использует тот же бандл и подменяет API VS Code на `localStorage`, поэтому там работает всё, кроме четырёх инструментов, выполняющихся в процессе расширения.

```
src/extension.ts      активация, команды, кнопка в строке состояния
src/sidebar.ts        лончер в Activity Bar (нативное дерево)
src/catalog.ts        сгенерированный каталог инструментов для лончера
src/panel.ts          жизненный цикл webview-панели
src/rpc.ts            обработчики на стороне Node (hash, gzip, certificate, RSA)
src/webview/          приложение webview (оболочка, инструменты, дизайн-система)
media/                HTML-шаблон, стили, иконки
```
