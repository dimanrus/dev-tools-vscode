## 🎉 [1.1.0] — 2026-11-21

### ✨ Added

- **🎞️ FFmpeg Converter** (`media-ffmpeg-convert`) — transcode, remux, trim, resize and extract audio with the local `ffmpeg`: MP4 (H.264/H.265), WebM (VP9/Opus), MKV remux, animated GIF, MP3/WAV/FLAC, CRF/encoder presets, NVENC/QSV/VA-API/VideoToolbox hardware encoding, source probing, a copyable command preview, live progress with speed/size, cancellation and output reveal.
- **📡 Stream Viewer** (`media-stream-viewer`) — probe and play RTSP (TCP/UDP/HTTP tunnel), RTMP(S), HLS, DASH, SRT, RTP, MPEG-TS over UDP/TCP, HTTP(S), FTP/SFTP, local files, concat lists and capture devices with `ffprobe`/`ffplay`; custom headers, User-Agent, Referer, optional low-latency flags (off by default), collapsible advanced settings, stream tables, PNG frame snapshots without a player window, ffplay logs and a ready-to-copy command. A reference table lists everything ffplay can open.
- **⚙️ Settings:** `devTools.ffmpegPath`, `devTools.ffprobePath` and `devTools.ffplayPath` let you point the tools at custom binaries.
- **📂 Explorer:** both tools appear in **Open in Dev Tools…**, and incoming files now keep their real filesystem path.
- **🔑 New "Cryptography" group with 7 tools:**
  - **Symmetric Encryption** — AES-128/192/256 in ECB, CBC, CTR, CFB, OFB, GCM, CCM, OCB, SIV, GCM-SIV, KW/KWP and XTS, plus ChaCha20, ChaCha20-Poly1305, XChaCha20(-Poly1305), Camellia, ARIA and SM4, with key/IV/AAD fields, PKCS#7 padding, authentication tags, text/hex/base64/file input and `.bin` export.
  - **GOST Encryption** — Kuznyechik, Magma (GOST R 34.12-2015) and GOST 28147-89 (S-box selection) in ECB, CBC, CFB, CTR, CTR-ACPKM, OFB, MAC, OMAC-ACPKM, MGM and KExp15/KWP key wrap, powered by [@li0ard/gost](https://github.com/li0ard/gost).
  - **GOST Hashes & Signatures** — Streebog-256/512, GOST R 34.11-94, HMAC, PBKDF2, KDF_GOSTR3411_2012_256, CPKDF, GOST R 34.10-2012 signatures and VKO key agreement.
  - **Asymmetric Encryption** — RSA (OAEP SHA-1/256/384/512, PKCS#1 v1.5), ECIES (ECDH P-256 + HKDF + AES-256-GCM) and SM2 (C1C3C2).
  - **Signatures & Key Exchange** — ECDSA P-256/384/521, Ed25519, secp256k1, RSA-PSS/PKCS#1, X25519 and ECDH secrets, PEM ⇄ JWK conversion and SHA-256 fingerprints.
  - **Key Derivation (KDF)** — PBKDF2, HKDF, scrypt, Argon2id and bcrypt.
  - **Classic Ciphers** — Caesar, ROT13/47, Atbash, Vigenère, rail fence, Playfair, XOR and one-time pad.
- **📄 Licensing:** complete `THIRD_PARTY_NOTICES.md` for all 24 bundled packages with full license texts in `licenses/` (regenerated by `npm run licenses`), the notices are now included in the VSIX, and the LGPL-3.0 lamejs encoder is shipped as a separate replaceable `media/vendor/lamejs.iife.js` script instead of being inlined into the minified bundle.
- **🔎 Licenses window:** an info button next to the language switch (and the “Third-party licenses” button on the home page) opens an in-app list of every bundled library with its version, license, purpose, a link to its repository and the full license text, plus a thank-you note to the maintainers; the **Dev Tools: Third-party licenses** command opens the same window.
- **🎨 Image Editor** in Graphic & Color: layered canvas, brush and eraser, shape and line drawing (rectangles, ellipses, lines, arrows), rectangle and lasso selection, text objects (font, size, color, bold, italic, alignment, opacity), image overlays with scaling, crop and cut-out of a selected region, layer reordering/visibility, custom-size new documents, document resizing (with or without content scaling) and PNG/JPEG/WebP export.
- **🧩 Vector Editor** in Graphic & Color: rectangles, ellipses, lines, arrows and freehand polylines with selection, moving and corner-resize, fill/stroke/opacity properties, SVG markup editing, SVG import from files and export to SVG or PNG.
- **🌤️ Image Adjustments** in Graphic & Color: exposure, brightness, contrast, highlights/shadows, saturation, vibrance, temperature, tint, vignette, grain and sharpening with presets, live histogram, before/after toggle and full-resolution export.
- **🎬 New "3D, Video & Audio" group:**
  - **Audio Editor** — waveform selection, 10-band equalizer, low/high-pass filter, gain, fades, normalization, playback and local WAV/MP3 export.
  - **Video Editor** — timeline trim handles, text/image/GIF overlays with per-clip timing, music track with volume mix, preview and WebM export via MediaRecorder.
  - **3D Scene** — primitive-based scene editor (box, sphere, cylinder, cone, torus, slab), standard materials, lights, shadows, orbit/pan/zoom camera, an expandable object tree with per-node visibility, OBJ/STL/GLB/GLTF import and PNG rendering up to 4K.
  - **CAD Editor** — SketchUp-style modelling with snapped footprints, face Push/Pull on any side, vertex/face/grid snapping, a line tool, precise metre dimensions, tape measure, layers, components and instances, a move/rotate/scale gizmo, saved camera scenes, solid/wireframe/blueprint styles, textures, OBJ/STL/GLB/FBX/DAE/3DS import and OBJ/STL/GLB/PNG export.
  - **Animation Studio** — 2D and 3D keyframe animation with a draggable timeline, per-object tracks, position/scale/rotation/opacity keys, SVG and model import, project save/load, Lottie JSON, animated GIF, PNG and WebM export.
  - **Media Metadata** — title, author, description, creation date and geo coordinates; embeds XMP into JPEG/PNG, ID3 into MP3 or exports a JSON sidecar, with Google/Yandex Maps links.
- **🏠 Home page & shell controls:** the panel opens on a full-width home grid with every tool grouped by category; a house button in the header returns to it. The tool sidebar can be hidden/shown, and light/dark themes switch right next to the language button (both remembered).
- **🎨 Shader Playground:** new tool for writing GLSL and HLSL fragment shaders with a live WebGL preview, **GLSL ES 1.00 and ES 3.00 (`#version 300 es`) support**, `uv`/`out` style shaders, `u_time`/`u_resolution`/`u_mouse` (vec2 or vec4) plus Shadertoy aliases, predefined `PI`/`TAU`/`E`, presets, resolution switch, a basic HLSL→GLSL transpiler, and PNG export. `#include "https://…"` is downloaded through the extension host and inlined (nested includes, relative paths); `<lygia/…>` resolves through the unpkg CDN, and failures are reported as warnings without breaking the preview.
- **🖱️ Explorer context menu:** **Open in Dev Tools…** for images, SVG, audio, video and 3D models opens the matching editor with the file already loaded.
- **📄 PDF Toolkit:** merge PDFs, delete/rotate/reorder pages, extract a selection, split into chunks and download the result.
- **🧪 Fake Data Generator:** RU/EN names (gender-consistent), phones, addresses, emails, companies, birth dates, usernames and passwords with reproducible seeds, column picker, custom templates and CSV/JSON export.
- **🔍 Regex tester:** 18 ready-made patterns, a separate **Groups** section (numbered and named groups) and synchronized flags.

## 🎉 [1.0.0] — 2026-11-07

### ✨ Added

- Initial public release of **Dev Tools** for VS Code 1.105+.
- Single webview panel with instant search (`Ctrl+K`), grouped navigation and 45 tools.
- Bilingual interface (English / Russian) with automatic detection of the VS Code display language and a manual switcher.
- **🔄 Converters:** Cron Parser, Date & Timestamp, JSON Array to Table / CSV, JSON ↔ YAML, Number Base, JSON → Code and XML → Code (C#, F#, TypeScript, JavaScript, PHP; System.Text.Json or Newtonsoft.Json for JSON, `System.Xml.Serialization` for XML, plus a copy-ready deserialization snippet for every target).
- **✏️ Text:** Escape / Unescape, List Comparer, Markdown Preview, Text Analyzer, Text Comparer.
- **🔐 Encoders / Decoders:** Base64 Text, Base64 Image, Certificate Decoder, GZIP, HTML Entities, JWT Decoder (decode, verify and sign), QR Code, URL Encode / Decode.
- **🧹 Formatters:** JSON, SQL, XML. Invalid JSON is reported with an exact line and column, even when the JavaScript runtime omits the position.
- **🎲 Generators:** Hash / Checksum (MD5, SHA-1/2, CRC-32, HMAC), Lorem Ipsum, Password, UUID (v4/v7/nil), ULID, RSA key pairs, Semver calculator.
- **🎨 Graphic & Color:** Color Tools (conversions, WCAG contrast, tints and shades), Color Blind Simulator, Image Converter.
- **🧪 Testers:** JSONPath, Regular Expression Tester, XML / XSD Validator.
- **⭐ Icons:** searchable built-in set of 95 Tabler-style outline icons with SVG copy.
- **📦 Extras:** Duplicate Detector, File Splitter, JSON Schema Generator, PNG Compressor, Randomizer, RESX Translator, Text Delimiter, XSD Generator.
- **🧭 Activity Bar launcher**: a native tree with all nine groups and 45 tools; picking a tool opens the wide editor panel on it. A view-title button opens the full panel.
- **📌 Status bar button** `$(tools) Dev Tools` that opens the panel directly, without touching the sidebar (toggle with `devTools.showStatusBar`).
- 🗂️ Tool catalog generated from the registry (`npm run catalog`), so the launcher can never drift from the actual tool list.
- ⚙️ Extension settings `devTools.language`, `devTools.startupTool` and `devTools.showStatusBar`.
- ⌨️ Command `Dev Tools: Open Dev Tools` with the `Ctrl+Alt+D` / `Cmd+Alt+D` keybinding.
- 🌗 Theme-aware design that follows VS Code light, dark and high-contrast themes.
- 🔒 Fully local processing: no telemetry, no network requests, no workspace access unless a file is dropped into a tool.
